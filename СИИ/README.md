## Особенности реализации

- Все алгоритмы машинного обучения реализованы **с нуля** (без использования `sklearn` для обучения), включая:
  - Метод наименьших квадратов + решение СЛАУ методом Гаусса
  - k-NN с векторным вычислением расстояний
  - Дерево решений ID3 с entropy / information gain
  - Логистическая регрессия (градиентный спуск + метод Ньютона)
- Prolog-часть включает онтологию из 35 персон с 38 правилами вывода
- Система рекомендаций поддерживает запросы на русском языке с морфологическим анализом
