# Flappy Bird + FreeRTOS (SDK-1.1M)

Игра **Flappy Bird** для учебного стенда **SDK-1.1M** (STM32F407VGTx) на базе **FreeRTOS** (CMSIS-RTOS v1).

Тема МК3: «Программирование микроконтроллеров с операционной системой (FreeRTOS)».

Собрано из официальных шаблонов:
- [SDK_FreeRTOS](https://github.com/lmtspbru/SDK-1.1M/tree/master/SDK_FreeRTOS)
- [SDK_OLED](https://github.com/lmtspbru/SDK-1.1M/tree/master/SDK_OLED)
- [SDK_Keyboard](https://github.com/lmtspbru/SDK-1.1M/tree/master/SDK_Keyboard)
- [SDK_Buzzer](https://github.com/lmtspbru/SDK-1.1M/tree/master/SDK_Buzzer)

## Аппаратная конфигурация

| Компонент | Интерфейс | Адрес | Примечание |
|-----------|-----------|-------|------------|
| STM32F407VGTx | — | — | Ядро Cortex-M4, 168 МГц |
| OLED SSD1306 128×64 | I2C1 | 0x78 | Дисплей |
| Клавиатура (PCA9538) | I2C1 | 0xE2 | 4×3, через расширитель портов |
| Зуммер | TIM2 CH1 (PA5) | — | PWM |

Тактирование: HSE 25 МГц → PLL → SYSCLK 168 МГц, AHB = 168 МГц, APB1 = 42 МГц, APB2 = 84 МГц.

## Управление

Любая кнопка клавиатуры стенда = **взмах / старт / рестарт**.

## Архитектура FreeRTOS

Проект использует **4 задачи**, синхронизированные через очереди и мьютексы:

| Задача | Приоритет | Стек | Роль |
|--------|-----------|------|------|
| `Task_Input` | AboveNormal | 256 | Опрос клавиатуры (PCA9538 по I2C), отправка событий в `inputQueue` |
| `Task_Game` | Normal | 256 | Игровая логика: физика птицы, движение труб, столкновения, подсчёт очков |
| `Task_Display` | BelowNormal | 768 | Отрисовка игрового поля на OLED 128×64 |
| `Task_Sound` | AboveNormal | 384 | Звуковое сопровождение: фоновая мелодия + звуковые эффекты (взмах, очки, смерть) |

**Синхронизация:**
- `gameMutex` — защита общего состояния `GameState_t` (доступ из Task_Game, Task_Display, Task_Sound)
- `i2cMutex` — защита шины I2C (Task_Input и Task_Display)
- `inputQueue` — очередь событий ввода (ёмкость 8, тип `uint16_t`)
- `soundQueue` — очередь звуковых событий `SoundEvt_t` (ёмкость 8)

**Конфигурация FreeRTOS** (`FreeRTOSConfig.h`):
- Вытесняющее планирование с квантованием времени
- 7 уровней приоритета
- Размер кучи: 20480 байт
- Частота тиков: 1000 Гц

## Игровая механика

- Птица падает под действием гравитации (`GRAVITY = 18/100 pix/тик`)
- Взмах задаёт вертикальную скорость `FLAP_VELOCITY = -90`
- Две трубы движутся справа налево со скоростью `PIPE_SPEED = 2`
- Зазор между трубами: `PIPE_GAP = 22 px`
- Столкновение с трубой или выход за границы экрана → Game Over
- Счёт увеличивается при прохождении трубы
- Сохраняется лучший результат (`best`)

## Звук

Звук генерируется через **TIM2 PWM** (Channel 1) на пьезо-зуммере:

| Событие | Звук |
|---------|------|
| Старт / рестарт | Восходящее арпеджио C5→E5→G5→C6 |
| Взмах | C6 (40 мс) + E6 (50 мс) |
| Набор очка | E5→G5→C6 |
| Game Over | Нисходящая мелодия G5→E5→C5→A4→F4→D4→G3 |
| Фон (Ready/Play) | Циклический мотив из 16 нот |

Громкость регулируется скважностью PWM (0 = mute, BUZZER_ARR/2 = максимальная громкость).

## Защита от гонок данных

Доступ к общему состоянию `g_game` защищён мьютексом `gameMutex`. Каждая задача делает **снимок** состояния под мьютексом и работает с локальной копией (например, Task_Display копирует `g_game` в `snap` и отрисовывает вне критической секции).

Доступ к шине I2C (клавиатура + OLED) защищён мьютексом `i2cMutex`.

```

```

## Как прошить (STM32CubeIDE)

1. Установить [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html).
2. **File → Open Projects from File System…** → указать папку `FlappyBird_FreeRTOS`.
3. Подключить стенд кабелем **USB DBG** (разъём `DBG USB`).
4. В Linux проверить порты: `ls /dev/ttyUSB*` — должны появиться `ttyUSB1` и `ttyUSB2`.
5. Выбрать конфигурацию **Debug**, нажать **Build** (Ctrl+B). Должно быть 0 errors.
6. **Run → Debug** (OpenOCD + `SDK11M.cfg`).
7. Нажать **F8** (Resume) для запуска.

После старта на OLED отображается **FLAPPY** → нажать любую кнопку → игра началась. После Game Over — снова нажать кнопку для рестарта.

## Отладочный UART

USART1 (PA9 TX, PA10 RX) пробрасывается через встроенный программатор (FTDI FT2232) в виртуальный COM-порт ПК (`/dev/ttyUSB2` в Linux). Используется для диагностики.
