## Лабораторная работа 6

**Тема:** Логистическая регрессия — предсказание выживаемости на Титанике.

**Что сделано:**
- Реализация **логистической регрессии с нуля** двумя методами оптимизации:
  - **Градиентный спуск (GD)** — поэтапное обновление весов.
  - **Метод Ньютона (Newton-Raphson)** — использование матрицы Гессе.
- Ручная реализация метрик: **Accuracy, Precision, Recall, F1-Score, Confusion Matrix**.
- Исследование гиперпараметров:
  - learning rate: 0.001–1.0
  - количество итераций GD: 100–10000
  - количество итераций Newton: 3–50
- Визуализация: распределения признаков, тепловая карта accuracy, кривые обучения, сравнение GD vs Newton.
- Финальная модель с лучшими параметрами.
