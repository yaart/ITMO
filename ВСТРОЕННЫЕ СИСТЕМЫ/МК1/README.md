# Bare-metal калькулятор на STM32C031C6 (Wokwi)

Учебный проект по мастер-классу МК1: калькулятор на микроконтроллере
STM32C031C6 (ARM Cortex-M0+) без операционной системы (bare-metal).

## Возможности

- Операции: сложение, вычитание, умножение, деление целых чисел.
- Ввод — матричная клавиатура 4×4.
- Вывод — 4-разрядный семисегментный индикатор TM1637.
- Сброс вычислений клавишей `C`.

### Назначение клавиш

- `0`–`9` — ввод цифр.
- `+` — сложение.
- `-` — вычитание.
- `*` — умножение.
- `/` — деление.
- `=` — выполнить вычисление.
- `C` — очистка и сброс.

## Формат работы

1. Ввести первое число.
2. Нажать операцию (`+`, `-`, `*`, `/`).
3. Ввести второе число.
4. Нажать `=` — на индикаторе отобразится результат.
5. Нажать `C` — сброс.

## Аппаратная часть

- Микроконтроллер: STM32C031C6 (Cortex-M0+), плата Nucleo-C031C6.
- Клавиатура: матричная 4×4 (Wokwi `membrane-keypad`).
- Индикатор: TM1637, 4 разряда, интерфейс CLK/DIO (bit-bang).
- Отладочный UART: USART2 (PA2/PA3) через Serial Monitor.

### Подключение клавиатуры

| Сигнал | Пин MCU |
|--------|---------|
| R1     | PB7     |
| R2     | PB6     |
| R3     | PA10    |
| R4     | PB3     |
| C1     | PB10    |
| C2     | PB4     |
| C3     | PB5     |
| C4     | PB2     |

Строки — выходы с открытым стоком (Open-Drain), столбцы — входы с подтяжкой Pull-Up.

## Как запустить

1. Открыть проект в Wokwi (ссылка ниже).
2. Нажать **Start Simulation**.
3. Работать с клавиатурой — результат появится на семисегментном индикаторе.

## Пример работы

| Нажатия           | Результат |
|-------------------|-----------|
| `1 2 + 3 =`       | 15        |
| `9 - 4 =`         | 5         |
| `6 * 7 =`         | 42        |
| `8 / 2 =`         | 4         |
| `1 2 3 + 4 C`     | 0         |

## Примечания

- Проект собран без HAL/LL — только прямая работа с регистрами (Memory-Mapped I/O).
- Опрос клавиатуры выполняется не чаще одного раза в 100 мс (защита от дребезга).
- Системный таймер SysTick генерирует прерывание каждые 1 мс и увеличивает `tickCount`.
- Ссылка на симулятор Wokwi: [https://wokwi.com/projects/475590185209361409](https://wokwi.com/projects/475590185209361409)

## Структура проекта

- `main.c` — инициализация периферии, главный цикл, логика калькулятора.
- `tm1637.c` / `tm1637.h` — драйвер семисегментного индикатора.
- `keyboard.c` / `keyboard.h` — драйвер матричной клавиатуры 4×4.
- `main.h` — определения регистров и структур периферии.
- `diagram.json` — схема подключения в Wokwi.
