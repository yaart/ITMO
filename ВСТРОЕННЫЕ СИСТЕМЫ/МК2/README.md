# Bare-metal калькулятор на стенде SDK-1.1M

Учебный проект: калькулятор на микроконтроллере STM32F427VIT6
без операционной системы (bare-metal).

## Возможности

- Операции: сложение, вычитание, умножение целых чисел.
- Ввод — матричная клавиатура 3×4.
- Вывод — OLED-дисплей 128×64 (SSD1306).
- Защита от переполнения: при выходе за `int32` на экран выводится `OVF`.

- `0`–`9` — ввод цифр.
- `ОП` — циклическое переключение операции: `+ → - → * → +`.
- `=` — выполнить вычисление.

## Формат вывода на дисплей
<первый_операнд> <операция>
<второй_операнд> =
<результат>

## Аппаратная часть

- Микроконтроллер: STM32F427VIT6 (Cortex-M4).
- Клавиатура и расширитель портов: PCA9538PW, интерфейс I2C (адрес `0xE0`).
- Дисплей: SSD1306, интерфейс I2C (адрес `0x78`).
- Отладочный UART: USART6 через встроенный программатор.

## Как собрать и залить

1. Открыть проект в STM32CubeIDE.
2. `Project → Build All`.
3. `Run → Debug`.
4. `F8` (Resume) - программа запустится на стенде.

## Пример работы

| Нажатия | Результат |
|---------|-----------|
| `1 2 3 ОП ОП 4 5 =` | 78 |
| `1 0 0 ОП ОП 2 0 0 =` | -100 |
| `1 2 ОП ОП ОП 3 =` | 36 |
| 8 девяток `ОП ОП` 8 девяток `=` | OVF |

## Примечания

- Стенд: SDK-1.1MC.427.

  [lmtspbru/SDK-1.1M](https://github.com/lmtspbru/SDK-1.1M),
