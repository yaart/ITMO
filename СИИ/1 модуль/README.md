## Лабораторная работа 1

**Тема:** Представление знаний — онтология британской королевской семьи.

**Что сделано:**
- Описана база знаний британской королевской семьи на **Prolog** (`british_royal_family.pl`) — 35 персон с фактами пола, дат рождения, смерти, браков и разводов.
- Определены **38 правил вывода**: мать, отец, ребёнок, сын, дочь, брат/сестра, дедушка/бабушка, прародители, предок/потомок, дядя/тётя, племянник/племянница, двоюродные братья/сёстры, супруг/супруга, бывший супруг, текущий супруг, вдовец/вдова и др.
- Экспорт онтологии в формате **OWL** (`british_royal_family.owl`).

**Файлы:**
| Файл | Описание |
|------|----------|
| `british_royal_family.pl` | База знаний на Prolog (факты + правила) |
| `british_royal_family.owl` | Онтология в формате OWL |

## Лабораторная работа 2

**Тема:** Система рекомендаций на естественном языке (NLP + Prolog).

**Что сделано:**
- Разработана **интерактивная вопросно-ответная система** на Python + Prolog для базы знаний британской королевской семьи.
- Поддержка запросов **на русском языке** с морфологическим анализом через `pymorphy3`.
- **Парсинг естественно-языковых запросов** двух типов:
  - `"найди <отношение> <имя>"` — поиск родственников (найди детей Елизаветы II)
  - `"кем является X для Y"` — определение отношения между двумя персонами
- Расширенная база знаний на Prolog (`royal_family.pl`) с русскими и английскими метками персон, отношением `what_is/3` и `find_relatives/4`.

**Зависимости:**
```
pip install pyswip pymorphy3
```
Также требуется установленный SWI-Prolog.

**Файлы:**
| Файл | Описание |
|------|----------|
| `recommender.py` | Основной скрипт вопросно-ответной системы |
| `royal_family.pl` | База знаний на Prolog (расширенная, с русскими метками) |
